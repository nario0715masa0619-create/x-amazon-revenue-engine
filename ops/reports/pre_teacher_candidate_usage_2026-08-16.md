# pre_teacher_candidate 3件の用途分離メモ（2026-08-16）

- 位置づけ: 本メモは **keep/drop の最終判定ではない**。Phase 1.1（本文ハッシュdedup）+ Phase 2.2（否定文脈対策）適用後に残った`pre_teacher_candidate`3件について、次サイクルでどの用途で参照するかを固定する運用メモ。
- 前提: 3件ともジャンル整合性（40代ファッション×ガジェット）は一定以上あるが、3件とも反応指標が弱く、[external_only_learning_policy_2026-08-14.md](external_only_learning_policy_2026-08-14.md)の「実績あり×構造近似」のうち**"実績あり"を十分に満たしていない**。よって3件すべてを主教師へ直行させず、用途を分けて保持する。

## 用途ラベルの定義

| ラベル | 意味 |
|---|---|
| `structure_observation` | 投稿の骨組み・話の立て方・比較/選別の型を観察するために残す |
| `approach_observation` | フック・見せ方・言い回し・ベネフィットの置き方を観察するために残す |
| `comparison_hold` | 次回以降、より強い実績投稿が見つかったときの比較対象として保留する |
| `not_for_primary_teacher_yet` | 現時点では主教師採用しないことを明示する |

## 対象3件と用途

### 1. 「片付けの最初の一歩は、実は財布がおすすめです」（財布の中身／断捨離／身軽に生きる）

- 暫定用途: `structure_observation` / `comparison_hold` / `not_for_primary_teacher_yet`
- 見るべき価値: 持ち物更新を「片付けの第一歩」に言い換える入口設計／財布という具体物を起点に生活改善・身軽さ・更新価値へつなぐ構造／40代文脈と持ち物見直しの接続
- 弱さ: 反応指標がかなり弱い／ファッション×ガジェットの交点としてはガジェット側が薄い／アプローチ教師というよりは構造観察寄り
- 運用判断: 主教師候補ではなく構造観察メモとして保持。財布/バッグ/小物整理/身軽化/所有物アップデート系のより強い投稿が見つかったときの比較対象に使う。単独で教師採用しない

### 2. 「【Tシャツ×ワイドパンツ】40代が着映えるコツは『小物使い』にアリ！」

- 暫定用途: `approach_observation` / `structure_observation` / `comparison_hold` / `not_for_primary_teacher_yet`
- 見るべき価値: 「40代が着映えるコツ」という年齢軸＋ベネフィット軸のフック／小物使いを改善ポイントとして前面化する構造／コツ提示型としての見出し・入口の作り方
- 弱さ: 反応指標が弱い／ガジェット接点は薄くファッション寄りに偏る
- 運用判断: 「40代」「着映え」「小物使い」の3点セットは今後も使えるため保持。主教師ではなく、ファッション寄り切り口のアプローチ教師補助として使う。ガジェット接点を含む類似投稿が取れたら比較対象にする

### 3. 「モンベルの日傘やミレーのキャップ…40代・50代が素敵に見えるアウトドアブランド小物5選」

- 暫定用途: `approach_observation` / `structure_observation` / `comparison_hold` / `not_for_primary_teacher_yet`
- 見るべき価値: 「素敵に見える」「小物5選」という選別・ランキング型／年齢軸と審美軸の結びつけ方／observe層で拾いたい「小物選定型」の上位互換候補
- 弱さ: 反応指標が弱い／メディア型で個人の強い使用実感・実績証明は薄い／ガジェット成分は薄い
- 運用判断: 3件の中で最も「選別型・ランキング型」の見本として使いやすい。主教師採用は保留だが、アプローチ観察素材としては価値が高い。より強い反応を持つ「40代×小物選定」投稿が見つかった場合の比較基準として残す

## 3件の相対整理

- 最も構造観察向き: 1. 財布の中身／断捨離／身軽に生きる
- 最もファッション寄りアプローチ観察向き: 2. Tシャツ×ワイドパンツ×小物使い
- 最も選別型・ランキング型の観察向き: 3. 40代・50代が素敵に見える小物5選

共通判断: 3件とも「残す価値はある」／3件とも「今の時点で主教師にしない」／3件とも「比較保留・観察用途」で扱う。役割は"採用候補"ではなく"参照候補"である。

## 次サイクルでの使い方

1. 主教師探索は継続する
2. この3件は、より強い実績投稿が見つかった時の比較対象にする
3. 構造教師／アプローチ教師の二層運用（[approach_structure_teacher_separation_2026-08-14.md](approach_structure_teacher_separation_2026-08-14.md)）では、財布投稿→構造観察寄り、小物使い投稿→ファッション寄りアプローチ観察、小物5選投稿→選別型アプローチ観察、として使い分ける
4. 次回も反応が弱いままなら、教師昇格ではなく観察メモとして固定する

## 最終メモ

この3件は「主教師候補そのもの」ではなく、「40代ファッション×ガジェット」ジャンルにおいてどの方向に型を伸ばせそうかを示す先行サンプルである。したがって現時点での扱いは、採用候補ではなく、用途分離された観察資産として保持するのが妥当である。
