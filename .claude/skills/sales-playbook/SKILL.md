# sales-playbook (販売モード)

## 目的

集客・教育で積み上げた興味・信頼をもとに、具体的な購入の意思決定を後押しし、Amazonアフィリエイトリンクへの遷移・コンバージョンを生む。3モードの中で最も表現の厳格さが求められるモード。

## 使う場面

- 現在モードが `sales`(`ops/state/current_mode.yaml`)のとき
- 教育モードで反応の良かった商品・テーマがあり、購買意欲が高まっていると判断されるとき
- セール・キャンペーンなど、時期的にCTAが刺さりやすいタイミング

## 入力

- growth-marketer による施策設計(狙うKPI・訴求角度が明確なもの)
- x-researcher による商品情報(価格・在庫・特徴の最新確認)

## 出力

- 販売向け投稿案(目的: 意思決定支援・購入誘導)
- 狙うKPI: `ctr`, `conversion`, `revenue`, `epc`
- **必ず `affiliate-compliance-reviewer` のレビューを経て `approved` になった案のみを最終投稿案とする**

## 設計方針

- CTAを明確にする(「詳細はこちら」「在庫のうちに確認」等、誤認のない範囲で)
- 意思決定に必要な情報(誰向けか、何が良いのか、注意点)を簡潔に示す
- 開示欄を必ず含める(`docs/policies/disclosure-policy.md` に準拠)
- 価格・在庫・キャンペーン情報は変動しうる旨を踏まえた表現にする(断定的な「今だけ」「必ず」を避ける)

## コンプラレビュー前提(必須)

販売モードの投稿案は、x-copywriterが作成した時点では未確定の「案」に過ぎない。`affiliate-compliance-reviewer` が以下を確認し `approved` としない限り、投稿・ログの `status` を `approved` にしてはならない。

- 開示欄の有無・明確さ
- 誇大表現・断定的効果効能の有無
- 価格・在庫表現の適切さ
- 比較表現の公正さ

## チェックポイント

- [ ] 開示欄が本文内に明確に含まれているか
- [ ] CTAが誤認を招く表現(緊急性の演出しすぎ等)になっていないか
- [ ] 価格・在庫情報が最新か、断定しすぎていないか
- [ ] `affiliate-compliance-reviewer` のレビューを経ているか

## 失敗例

- 開示欄を省略、または本文の目立たない位置に埋め込んでしまう
- 「絶対に得」「今すぐ買わないと損」など、根拠のない緊急性・断定表現を使う
- レビュー未完了のまま投稿案を確定として扱ってしまう
- 教育モードで積み上げた信頼を無視し、いきなり強いCTAだけの投稿をする
