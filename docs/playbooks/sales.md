# sales.md — 販売モードの考え方（人間向け）

対応する実行用skill: [.claude/skills/sales-playbook/SKILL.md](../../.claude/skills/sales-playbook/SKILL.md)

## なぜ販売モードが最も厳格なのか

販売モードは実際の収益に直結する分、表現のリスク（誇大広告、開示漏れ、誤認表現）が最も高い。集客・教育で積み上げた信頼を、1件の不適切な投稿で損なうことがないよう、このモードだけは必ずコンプライアンスレビューを経る運用にしている（[CLAUDE.md](../../CLAUDE.md)）。

## 販売モードで意識すること

- **意思決定支援に徹する**: 「買ってください」ではなく「こういう人にはこれが向いている、詳細はこちら」という形で、読者自身の判断を後押しする
- **CTAは明確に、誤認は生まない**: リンク先で何が見られるかを明確にする。誇張した緊急性（「今だけ」「絶対お得」）は使わない
- **開示は必須**: 開示欄のない販売モード投稿は存在してはならない（[disclosure-policy.md](../policies/disclosure-policy.md)）
- **価格・在庫は慎重に**: 変動しうる情報を断定的に書かない（[amazon-affiliate-policy.md](../policies/amazon-affiliate-policy.md)）

## 運用フロー

```
growth-marketer が施策設計
   ↓
x-copywriter が投稿案作成（開示欄を含む）
   ↓
affiliate-compliance-reviewer がレビュー ← 必須。ここを飛ばして投稿確定しない
   ↓
approved になったもののみ投稿
   ↓
logger がログ化
```

## よくある勘違い

- 「販売モードは数を打つほど成果が出る」→ 誤り。教育モードで信頼を積み上げていない状態で販売投稿を連発すると、フォロー解除や信頼低下を招く
- 「レビューは形式的な確認」→ 誤り。レビューは差し戻しを前提とした実質的なゲートであり、通すことが目的化してはならない

## 成果の見方

販売モードの成果（`ctr`, `conversion`, `revenue`, `epc`）は、その投稿単体の出来だけでなく、集客・教育モードでの積み上げの結果でもある。単体のKPIが悪い場合、販売モードの文案だけでなく、ファネル全体（[funnel-definition.md](../strategy/funnel-definition.md)）を見直す視点を持つ。
