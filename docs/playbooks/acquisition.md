# acquisition.md — 集客モードの考え方（人間向け）

対応する実行用skill: [.claude/skills/acquisition-playbook/SKILL.md](../../.claude/skills/acquisition-playbook/SKILL.md)

## なぜ集客が起点なのか

Amazonアフィリエイトの収益は、最終的には「誰かがリンクをクリックして購入する」ことで生まれる。しかしいきなり販売を訴求しても、アカウントを知らない・信頼していない相手には響かない。集客モードは、このファネル全体の母数を作る役割を担う。

## 集客モードで意識すること

- **知らない人に見つけてもらう**: すでにフォローしている人向けの内容ではなく、タイムラインで偶然目にした人が反応できる内容にする
- **売らない**: このモードの投稿で商品購入を訴求しない。訴求してしまうと、教育・販売モードとの役割分担が崩れ、[funnel-definition.md](../strategy/funnel-definition.md) の設計が意味をなさなくなる
- **保存・引用したくなる情報密度**: 単発でも価値のある情報（豆知識、あるある、意外な事実）を心がける
- **プロフィールへの興味喚起**: 「この人は他に何を発信しているのか」と思わせる終わり方を意識する

## よくある勘違い

- 「集客モードだからフォロワーを増やすためにとにかく投稿数を増やす」→ 誤り。品質を落とした量産はアカウント健全性を損なう（[x-posting-policy.md](../policies/x-posting-policy.md)）
- 「集客モードでも軽くリンクを貼っておけば良い」→ 誤り。集客モードの目的はリンククリックではなく興味喚起とプロフィール遷移

## 次のモードへのつながり

集客モードで興味を持った人が、教育モードの投稿で理解を深める。集客単体では収益は生まれない。集客の成果（`follow_rate` 等）は、教育・販売モードの母数として効いてくることを意識する。
