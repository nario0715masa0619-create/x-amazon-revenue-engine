# education.md — 教育モードの考え方（人間向け）

対応する実行用skill: [.claude/skills/education-playbook/SKILL.md](../../.claude/skills/education-playbook/SKILL.md)

## なぜ教育が間に必要なのか

集客で興味を持ってもらっても、いきなり商品を勧められると「売り込みされている」と感じられ、信頼を損なう。教育モードは、商品カテゴリの理解を深め、「この人の言うことは参考になる」という信頼を積み上げる役割を担う。

## 教育モードで意識すること

- **比較軸を提供する**: 「何を基準に選べばよいか」を示す。特定商品の宣伝ではなく、判断材料の提供が目的
- **失敗回避を扱う**: 「よくある失敗」「選び方を間違えるとどうなるか」は保存・信頼につながりやすいテーマ
- **断定を避ける**: 「これが一番」ではなく「こういう人にはこれが向いている」という、条件付きの提示にする
- **保存したくなる構造化**: 箇条書き、比較表など、後で見返したくなる形式にする

## よくある勘違い

- 「教育モードだから商品を出してはいけない」→ 誤り。商品を出すこと自体は問題ないが、断定的な優劣付けや強いCTAを避ける（それは販売モードの役割）
- 「情報量が多ければ多いほど良い」→ 誤り。網羅性より、読者が実際に使える判断軸を絞って示す方が保存・信頼につながる

## 次のモードへのつながり

教育モードで信頼を積み上げた読者が、販売モードでの具体的な提案を受け入れやすくなる。教育モードの成果（`save_rate`、`reply_rate`）は、販売モードの転換率に間接的に効いてくる。
