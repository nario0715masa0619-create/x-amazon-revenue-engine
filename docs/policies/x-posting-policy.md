# x-posting-policy.md — X運用ポリシー

このポリシーは、X（旧Twitter）上でのアカウント健全性を維持しながら発信するための基本方針を定める。

## 1. 同一文面量産の回避

- 同じ構文・同じフックを繰り返し使い回さない。`logger` が記録する `post_log.jsonl` を確認し、直近投稿と類似度が高い文案は避ける
- 同一商品を扱う場合でも、切り口（訴求角度）を変える。同じ商品×同じ角度の連投はしない
- テンプレートは構造の型であり、そのまま埋めるだけの機械的な運用にしない

## 2. 不自然な自動化の回避

- 現時点でこのリポジトリは投稿の自動化を行わない（[CLAUDE.md](../../CLAUDE.md) 参照）。将来自動化する場合も、投稿間隔・頻度が不自然に一定になる設計は避ける
- 大量の同時投稿、短時間での連投は避ける
- リプライ・いいねなどのエンゲージメント行動を機械的に量産しない

## 3. 品質優先

- 投稿数（頻度）よりも、1件あたりの質（フックの強さ、情報の正確さ、読みやすさ）を優先する
- 「とりあえず投稿する」ための投稿は作らない。目的（狙うKPI）が説明できない投稿は正式化しない
- 誤字・事実誤認のチェックを経ずに投稿を確定させない

## 4. アカウント健全性の重視

- スパム判定・凍結リスクを避けるため、外部リンクの貼り方（本文内の数・位置）に配慮する
- フォロー/アンフォローの繰り返しなど、プラットフォームの規約に抵触しうる行動を行わない
- 通報・批判が集まりやすい表現（誇大広告、誤情報、扇動的な物言い）を避ける。詳細は [amazon-affiliate-policy.md](amazon-affiliate-policy.md)、[disclosure-policy.md](disclosure-policy.md)
- アカウントの長期的な信頼が短期的なクリック数より優先される

## 適用範囲

このポリシーは集客・教育・販売のすべてのモードに適用される。モード別の追加ルールは各playbook（[docs/playbooks/](../playbooks/)、`.claude/skills/`）を参照する。
