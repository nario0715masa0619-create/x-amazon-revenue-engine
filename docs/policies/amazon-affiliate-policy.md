# amazon-affiliate-policy.md — Amazonアフィリエイト運用ポリシー

Amazonアソシエイト・プログラムの精神と一般的な広告表示ルールを踏まえた、このプロジェクトにおける基本注意点をまとめる。実際の運用にあたっては、必ず Amazon アソシエイト・プログラムの最新の公式規約を確認すること。このドキュメントは社内向けの運用チェックリストであり、規約そのものの代替ではない。

## 1. 誤認を招く表現を避ける

- 「必ず」「絶対に」「誰でも」など、効果や結果を保証する表現を使わない
- 自分が実際に確認・体験していない性能・効果を断定的に書かない
- 競合商品を根拠なく貶める比較表現をしない
- 公式のセール・キャンペーンでないものを、あたかも公式キャンペーンであるかのように書かない

## 2. 価格・在庫の扱い

- 価格・在庫・クーポンは変動が激しい情報である。投稿時点の情報として書き、「現在の価格」「執筆時点」等、変動しうることが伝わる表現にする
- 「今だけ」「二度とない」など、価格変動の緊急性を過度に演出しない
- 価格を明記する場合、確認日時をx-researcherの調査結果に残す（投稿本文に含めるかは任意だが、根拠は追跡できるようにする）

## 3. 断定表現の注意

- 効果効能（特に健康・美容・医療に関わる商品）について、断定的な効能効果を主張しない
- レビュー・評価は「多くのレビューで〜と言われている」等、情報源が推測できる書き方にする
- 個人の感想と、客観的な仕様・スペックを混同して書かない

## 4. リンクの扱い

- アフィリエイトリンクを使用する投稿には、必ず開示を伴う（[disclosure-policy.md](disclosure-policy.md)）
- リンク先商品の情報（価格・仕様）と投稿本文の記載に齟齬がないか、投稿前に確認する
- 商品が終売・入手困難になった場合、該当投稿の扱いを見直す（このリポジトリでは現状は手動確認とする）

## 5. レビュー担当との関係

このポリシーの適用判定は `affiliate-compliance-reviewer` が行う（[docs/roles/compliance.md](../roles/compliance.md)）。販売モードの投稿は必ずこのレビューを経る（[CLAUDE.md](../../CLAUDE.md) 参照）。
