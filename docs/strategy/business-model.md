# business-model.md — 事業モデル

## 何を収益化するのか

このプロジェクトは、X上での発信を起点として Amazon アソシエイト・プログラム（アフィリエイト）経由の紹介料収益を生み出すことを目的とする。

収益源は単一で、「X上のコンテンツ経由でAmazon商品ページへ遷移した閲覧者が購入することで発生する紹介料」である。広告出稿や他の収益源(スポンサー投稿、独自商品販売等)は現時点のスコープ外とする。

## 収益化の流れ

```
X上での発信
   │
   ▼
①集客モード ── 新規接触・フォロー・プロフィール遷移
   │
   ▼
②教育モード ── 商品カテゴリ理解・比較軸提供・信頼構築
   │
   ▼
③販売モード ── 具体的な商品提案・CTA・Amazonリンクへの誘導
   │
   ▼
Amazon商品ページ ── 閲覧・購入
   │
   ▼
成果計測 ── クリック・コンバージョン・報酬額をログ化
   │
   ▼
週次PDCA ── 何が効いたかを分析し、次サイクルに反映
```

この一連の流れが「X → 教育 → Amazon送客 → 成果計測」というこのプロジェクトの基本ループである。

## 収益の構成要素

紹介料収益は、大まかに以下の掛け算で決まる:

```
収益 ≈ リーチ(集客) × 信頼・理解度(教育) × 転換率(販売の質) × 商品単価/成約率(商品選定)
```

したがって、どれか1つのモードだけを強化しても収益は頭打ちになる。3モードはそれぞれ独立したKPIを持ちながら、直列につながったファネルとして設計する（詳細は [funnel-definition.md](funnel-definition.md)）。

## このモデルにおける「担当」の位置づけ

- x-researcher / growth-marketer は「何を・誰に・どう伝えるか」の精度を上げることで転換率と信頼を底上げする
- x-copywriter / affiliate-compliance-reviewer は「発信の質と安全性」を担保する
- performance-analyst / logger は「どの施策が効いたか」を可視化し、次サイクルの精度を上げる

収益は投稿1件の巧拙ではなく、このループが正しく回り続けることで積み上がる。そのためログとPDCA基盤(このリポジトリの中核)を最初に整える。

## 現時点でやらないこと

- 自動投稿・自動リンク生成などの本番自動化
- 複数商品カテゴリを横断した大規模な商品データベース運用
- Amazon以外のアフィリエイトプログラムとの併用
- 有料広告によるリーチ購入

これらは初期骨格が安定してから、拡張ポイントとして検討する（[README.md](../../README.md) の「今後の拡張ポイント」を参照）。
